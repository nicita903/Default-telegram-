# Interface designs — superseded

This file described the two earlier appearance implementations: Telegram Glass and Soft Console
(`PixelTerminal`). Both designs, and the Light/Dark/System theme modes that went with them, have been
removed from the app.

There is now a single theme: [Aurora](AURORA.md). The palette, materials, shapes, typography, module
menu and gesture feedback are documented there.

The earlier reports remain for history:

- [SOFT_CONSOLE.md](SOFT_CONSOLE.md) — the 0.6 Soft Console implementation and its verification.
- [design-concepts/](design-concepts/index.html) — the four explored directions that led to Aurora.
